# 🌐 Web Development Portfolio

Welcome to my **Web Development Portfolio**, a collection of full-stack and frontend web projects built using modern JavaScript technologies. This repository showcases a variety of applications focused on authentication, text processing, and API integration.

---

## 📁 Projects Overview

### 🔐 [Full-Stack Auth App](./Full-Stack%20Auth%20App)

A complete authentication system built with Node.js, Express, and MongoDB. Features include:

- User registration & login with `bcrypt` hashing
- Role-based access control (admin/user)
- Express-session for session tracking
- Theme customization per user
- Protected routes via custom middleware

➡️ [Read Full README](./Full-Stack%20Auth%20App/README.md)

---

### ✍️ [Frontend Text Analysis Tool](./frontend-text-analysis)

A lightweight client-side application that analyzes user input text in real time.

- Counts letters, words, vowels, consonants
- Highlights long/short word usage
- Built with vanilla JavaScript + Bootstrap
- Zero backend – runs entirely in browser

➡️ ➡️ [Read Full README](./frontend-text-analysis-tool/README.md)

---

### 🎬 [Full-Stack Movie App](./full-stack-movie-app)

A movie management system using MongoDB and Express API. Features:

- Create/edit/delete movies and reviews
- RESTful API structure
- Modular routing and database helpers
- Great for learning CRUD with NoSQL

➡️ [Read Full README](./full-stack-movie-app/README.md)
